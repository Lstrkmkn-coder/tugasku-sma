📲 Cara Jadikan Aplikasi di Layar Utama HP

Aplikasi TugasKu SMA ini berjalan 100% offline tanpa kuota internet. Biar gampang dibuka kayak aplikasi Android/iPhone biasa:

  1. Pastikan file TugasKu-SMA.html ini dibuka menggunakan browser Google Chrome (Android) atau Safari (iPhone).
  2. Ketuk ikon menu titik tiga (⋮) di pojok kanan atas Chrome (atau tombol Share di Safari).
  3. Pilih "Tambahkan ke Layar Utama" (Add to Home Screen), lalu tekan Tambah.
  4. Ikon TugasKu SMA akan langsung muncul di layar depan HP kamu!
